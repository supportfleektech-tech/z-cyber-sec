# Acceptance Criteria

A release is accepted only when:
- Environment and version are recorded.
- Core user flows pass automated tests.
- RBAC is enforced server-side and tested.
- Lab-to-management prohibited paths are shown blocked.
- Integrations expose health, errors, and provenance.
- Synthetic events produce expected alert/case behavior.
- Agent actions are scoped, auditable, and approval-gated.
- No secrets are committed or exposed in logs/artifacts.
- Persistent data backup and restore are demonstrated.
- Deployment and rollback instructions work on a clean target.
- Documentation matches implementation.
- Unresolved risks and limitations are explicitly accepted by an authorized owner.
