# CYBER-SEC Project Plan

## Objective
Build an integrated, local-first cybersecurity lab and operations platform on the existing host, with safe isolation, reproducible infrastructure, modular defensive capabilities, governed AI assistance, and a verified path to production.

## In scope
11 capability areas listed in README; core dashboard/API/auth/audit; integration contracts; local infrastructure; testing; documentation; production migration plan.

## Out of scope by default
Unauthorized testing; public exposure of vulnerable targets; automatic destructive response; unrestricted autonomous production changes; collection of real personal data without a documented lawful basis.

## Principles
Secure by default; source provenance; incremental delivery; least privilege; measurable acceptance; reversible changes; truthful status.

## Success
A clean, documented setup can be reproduced; core user flows and authorization tests pass; lab isolation is demonstrated; backups restore; agent tools respect policy; production release can be traced and rolled back.
