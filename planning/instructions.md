# Instructions for Contributors & Agents

1. Inspect before modifying.
2. Label facts Verified / Previously reported / Proposed / Unknown / Blocked.
3. Preserve working services and data.
4. Use a branch and small changes.
5. Define acceptance criteria before implementation.
6. Add tests and update docs with each feature.
7. Never expose secrets or paste them into agent context.
8. Never run destructive host/Docker commands without explicit approval and recovery plan.
9. Keep testing scoped to owned or explicitly authorized systems.
10. Report exact files changed, commands run, results, limitations, and next actions.
11. Do not claim installation, test, push, or deployment success without observed confirmation.
